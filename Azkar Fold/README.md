# Azkar Fold - Islamic Prayer Counter App

## Overview

Azkar Fold is a beautiful and intuitive iOS app designed to help Muslims keep track of their daily Azkar (remembrance of Allah) and Sunnah prayers. The app features a clean, modern interface with Islamic design elements.

## Features

### 📿 Custom Azkar Counter
- Create your own Azkar with custom text
- Tap-to-count interface with smooth animations
- Beautiful Islamic pattern background
- Persistent counter storage

### 🕌 Sunnah Azkar
- Pre-loaded Morning and Evening Azkar from authentic sources
- Progress tracking for each Azkar category
- Repetition counter for each Zekr
- English translations included
- Completion tracking and alerts

### 🎨 Beautiful Design
- Islamic geometric patterns
- Carefully chosen color palette
- Smooth animations and transitions
- Dark mode support
- Custom launch screen

### 📱 User Experience
- Split-screen layout for optimal readability
- Intuitive navigation
- Responsive design for all iOS devices
- Offline functionality - no internet required

## Technical Details

### Built With
- SwiftUI
- iOS 14.0+
- Xcode 16.1+
- Swift 5.0

### Architecture
- MVVM pattern
- ObservableObject for state management
- UserDefaults for local data persistence
- Navigation Coordinator pattern

### Data Storage
- All data stored locally on device
- No external servers or cloud storage
- Complete privacy - no data collection

## Privacy

Azkar Fold is designed with privacy as a core principle:

- No internet connectivity required
- All data remains on your device
